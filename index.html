Google Sheets ulanish Ulanmagan
To'lovlar hisoboti Google Sheets'ga yoziladi.
1. sheets.new — yangi jadval oching
2. URL'dan Sheet ID nusxalang: docs.google.com/spreadsheets/d/SHEET_ID/edit
3. OAuth Playground → Google Sheets API v4 scope tanlang → Authorize → Exchange authorization code for tokens → Access token'ni nusxalang
Token taxminan 1 soat amal qiladi — eksportdan oldin yangilab turing. Avtomatik saqlanadi.

Notion ulanish Ulanmagan
Loyihalarni Notionga bir tugma bilan chop etish.
1. notion.so/my-integrations → New integration → Internal yarating, Internal Integration Secret'ni nusxalang (ntn_... yoki secret_...)
2. Notionda loyihalar saqlanadigan sahifani oching → ••• → Connections → integratsiyangizni qo'shing
3. Sahifa URL'idan ID nusxalang: notion.so/SAHIFA_ID?v=... (oxirgi 32 ta belgi)
Notion brauzerdan to'g'ridan-to'g'ri so'rovni rad etadi. Cloudflare Worker yoki shunga o'xshash oddiy proxy URL kiriting (api.notion.com'ga yo'naltiruvchi). Avtomatik saqlanadi.
